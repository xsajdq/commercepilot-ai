# packages/pricing

Deterministic pricing engine: cost, VAT, marketplace fee, payment fee,
shipping, target/minimum margin, competitor prices, stock, and sales
velocity in; `minimum_price`, `recommended_price`, `maximum_price`,
`expected_margin`, `reason`, `confidence` out.

Empty scaffold — built in Phase 9, before any AI pricing agent. The math
here is plain code, never delegated to an LLM; the AI layer only
interprets and narrates its output.
